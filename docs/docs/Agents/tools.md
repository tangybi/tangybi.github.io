## 智能健身教练

通过可穿戴设备监测用户的心率、运动强度等生理数据
根据用户的健身目标（减脂/增肌/提升耐力）动态调整训练计划
在用户运动过程中提供实时语音指导和动作纠正
评估训练效果并给出饮食建议

PEAS 模型来精确描述一个任务环境，即分析其性能度量(Performance)、环境(Environment)、执行器(Actuators)和传感器(Sensors)

| 维度 | 说明 | 具体内容 |
|------|------|----------|
| **P** Performance | 性能度量 | 动作计数准确率、训练完成率、目标达成度、动作规范性评分、受伤预防、用户满意度、反馈延迟 |
| **E** Environment | 环境 | 家庭/健身房场景、用户身体状态（姿态/心率/疲劳度）、健身器材、时间日程、网络条件 |
| **A** Actuators | 执行器 | 语音指导、屏幕动作示范、姿态骨架叠加、训练计划动态调整、消息推送、触觉反馈 |
| **S** Sensors | 传感器 | RGB/深度摄像头、麦克风、加速度计/陀螺仪、心率传感器、GPS、触摸屏 |
