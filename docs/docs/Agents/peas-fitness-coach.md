# 小工具

# 智能健身教练 — PEAS 模型

## 概述

PEAS 是人工智能中用于定义智能体任务环境的框架，包含四个维度：
**P**erformance Measure（性能度量）、**E**nvironment（环境）、**A**ctuators（执行器）、**S**ensors（传感器）。

---

## 智能健身教练 PEAS

| 维度 | 内容 |
|------|------|
| **P — 性能度量** | 动作计数准确率、训练计划完成率、用户健身目标达成情况、动作规范性评分、受伤预防效果、用户留存率与满意度、实时反馈延迟 |
| **E — 环境** | 家庭/健身房场景、用户身体状态（姿态、心率、疲劳度）、健身器材（哑铃、瑜伽垫、跑步机等）、时间与日程、网络连接质量 |
| **A — 执行器** | 语音指导与纠正、屏幕动作示范（2D/3D 动画）、实时视觉反馈（姿态叠加）、训练计划动态调整、文字消息推送（鼓励/提醒） |
| **S — 传感器** | RGB/深度摄像头（姿态估计）、麦克风（语音指令）、可穿戴设备（心率、加速度计、陀螺仪）、触摸屏/键盘输入、智能手表/手环数据接口 |

---

## 详细说明

### Performance Measure（性能度量）

| 指标 | 说明 |
|------|------|
| 动作计数准确率 | 正确识别并计数用户完成的动作次数，避免漏计、误计 |
| 训练计划完成率 | 用户按照推荐计划完成训练的比例 |
| 健身目标达成度 | 减脂、增肌、耐力提升等长期目标的达成情况 |
| 动作规范性评分 | 对用户动作标准程度进行量化评分，识别错误姿态 |
| 受伤预防 | 在检测到危险动作时及时警告，降低受伤风险 |
| 用户满意度 | 通过评分、留存率、NPS 等衡量用户体验 |
| 反馈实时性 | 从检测到动作偏差到给出纠正建议的延迟（目标 < 100ms） |

### Environment（环境）

| 要素 | 说明 |
|------|------|
| 物理空间 | 室内（家庭、健身房）或室外（公园等），光线、遮挡情况多变 |
| 用户身体状态 | 身高、体重、肢体长度、当前心率、疲劳程度、过往伤病 |
| 器材环境 | 有无器材、器材类型（哑铃、弹力带、器械等）、器材位置 |
| 时间上下文 | 训练时段（早/中/晚）、训练时长、休息间隔 |
| 网络环境 | 在线/离线状态，带宽影响视频传输与实时反馈 |
| 社会环境 | 是否有他人同在（私教、训练伙伴），是否在公共场合 |

### Actuators（执行器）

| 执行器 | 具体行为 |
|--------|----------|
| 语音合成 | 发出"下蹲再深一点""呼吸均匀"等实时语音指导 |
| 屏幕显示 | 展示动作示范动画、用户姿态骨架叠加、实时评分面板 |
| 计划生成 | 根据用户目标与历史数据自动生成/调整训练计划 |
| 消息推送 | 训练提醒、激励消息、进度报告 |
| 震动/触觉 | 通过可穿戴设备发出震动提醒（如动作到位时） |
| 社交互动 | 分享训练成果到社区、发起挑战、组队训练 |

### Sensors（传感器）

| 传感器 | 感知内容 |
|--------|----------|
| RGB 摄像头 | 用户全身/上半身 2D 图像，用于姿态估计（如 MediaPipe、OpenPose） |
| 深度摄像头 | 获取 3D 骨骼信息，提升姿态估计精度（如 Kinect、Intel RealSense） |
| 麦克风 | 接收语音指令（"开始训练""下一组"）、检测呼吸频率 |
| 加速度计/陀螺仪 | 内置于手机或可穿戴设备，检测动作速度、方向、震动 |
| 心率传感器 | 实时心率监测，评估运动强度 |
| GPS | 户外跑步/骑行路线记录 |
| 触摸屏 | 用户手动输入目标、偏好、反馈 |

## 任务环境属性

| 属性 | 取值 | 说明 |
|------|------|------|
| 完全可观察？ | 部分可观察 | 无法直接感知用户肌肉疲劳度、内在动机等 |
| 确定性？ | 随机性 | 用户动作存在随机变异，外部环境有不可预测因素 |
| 片段式？ | 延续式 | 训练跨越多个会话，长期跟踪用户进步 |
| 静态？ | 动态 | 用户身体状态、环境条件随时间变化 |
| 离散？ | 连续 | 动作姿态是连续的空间坐标，时间也是连续的 |
| 单智能体？ | 单智能体 | 主要面向单个用户，但可扩展至多用户社交场景 |
| 已知规则？ | 已知 | 健身动作规范、生理学原理已知，但用户执行有偏差 |

## 典型场景示例

> 用户打开手机 App，将手机靠墙放置，摄像头对准自己。App 识别出用户身份并加载今日训练计划。用户开始做深蹲，AI 教练通过姿态估计实时检测到膝盖超过脚尖，立即通过语音提醒"注意膝盖不要超过脚尖"，并在屏幕上用红线标注偏差角度。训练结束后，AI 生成动作质量报告并调整明日的训练负荷。
