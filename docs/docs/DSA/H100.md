## 双指针

三种策略：
- 左右指针相向移动，直到left >= right
- 同向移动，右指针滑动寻找信息，左指针移动记录信息（滑动窗口）
- 分阶段遍历，先第一个指针寻找直到满足确定的条件，再用第二个指针遍历寻找满足其他条件的

什么时候使用？

通常是线性结构比如数组、链表，有序数组（有序的动态）、回文字符串。结果可以由2个值或一对值生成。

真实案例：
垃圾回收算法：内存压缩中，scan扫描指针和free释放指针。

[**167.排序数组两数之和**](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/description/)

直觉：
双指针

解：
两数之和可以用哈希表，但是哈希表需要 $O(n)$ 的空间，题目要求限制在常量级空间。

::: code-group

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left, right = 0, len(numbers) - 1
        while left < right:
            two_sum = numbers[left] + numbers[right]
            if two_sum == target:
                return [left + 1, right + 1]
            elif two_sum < target:
                left += 1
            else:
                right -= 1

```

```ts
function twoSum(numbers: number[], target: number): number[] {
    let left = 0, right = numbers.length - 1
    while (left < right) {
        let s = numbers[left] + numbers[right]
        if (s === target) {
            return [left + 1, right + 1];
        }
        s > target ? right-- : left++;
    }

};

```

 **3数之和**：a 、b、c, b+c = -a，先将数组排序，遍历a，剩下的i+1，n数组找2数之和。注意1、a可能重复；2、b可能重复。时间复杂度：$O(n^2)$ ,空间复杂度：$O(n)$ 。这里空间复杂度不算输出的空间，如果加上输出的空间那就是 $O(n^2)$
